# 抓取逻辑测试脚本 (Scraping Tests)

本目录包含我们在重构和排查爬虫逻辑时编写的一系列**独立测试脚本**。
由于直接在完整的后端框架中调试爬虫（需要登录、代理、全套依赖）比较繁琐，这些脚本可以在不需要启动整个后端服务的情况下，直接通过 Node.js 独立运行，极大地提高了爬虫规则编写和修复的效率。

如果您未来需要**维护旧站点的爬虫**或**开发新站点的插件**，可以复用并参考这些脚本。

## 核心脚本说明

### 1. 离线/模拟测试 (Offline Parsing)
这类脚本读取本地预先保存的 HTML 文件进行解析测试，不需要连接网络，不涉及代理，专用于调试 Cheerio 解析规则（如 DOM 选择器、正则匹配等）。
- **`cycani_home.html`**: 预先下载好的次元城首页 HTML 文件，作为离线测试的 Mock 数据源。
- **`test_fallback.js`**: 读取 `cycani_home.html`，测试当专用时间表页面失效时，如何从首页 DOM 结构中提取星期几（周一至周日）的新番数据以及封面图片。
- **`test_home.js` / `test_list.js` / `test_schedule.js`**: 包含用于测试首页轮播图、推荐列表、分类列表等具体模块的隔离测试逻辑。

### 2. 在线集成测试 (Live Integration)
这类脚本会加载完整的环境变量（如代理配置）和插件管理器（`PluginManager`），直接模拟后端服务向目标网站发起的真实 HTTP 请求。
- **`test_live.js`**: 测试完整的网络链路。它会读取根目录下的 `.env` 环境变量，初始化 `PluginManager`，并调用 `getWeeklySchedule` 等真实插件方法。用于验证在当前网络环境和代理配置下，后端是否能真正绕过防火墙或反爬虫机制拿到数据。
- **`test_plugin.js`**: 验证插件管理器的初始化机制，测试是否能正确识别和加载已安装的各个视频源插件。

## 使用方法

在项目的 `backend/` 目录下执行这些脚本：
```bash
# 运行离线解析测试（极速，无需网络）
node scripts/scraping-tests/test_fallback.js

# 运行真实的网络连通性与插件测试
node scripts/scraping-tests/test_live.js
```

## 注意事项
这些脚本主要是开发和调试工具，不属于核心生产代码。其中的本地路径（如 `require` 和读取文件的路径）由于移动到了本目录，直接运行时可能需要根据您的当前工作目录 (`cwd`) 稍作调整。
